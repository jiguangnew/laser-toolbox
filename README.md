# 激光切割工具箱 · 自动打断口

依据《断口实战手册》v1.0，把"会不会掉"的老师傅经验变成脚本。

## 文件

| 文件 | 说明 |
|---|---|
| `auto_tab.py` | 主脚本：自动打断口 |
| `断口实战手册.md` | 规则手册（人看的） |
| `make_test_dxf.py` | 测试图生成器 |
| `test_input.dxf` / `test_spline.dxf` | 测试图（含嵌套块/重复线/样条等坑） |

## 安装

```bash
# venv 已建好（VM 重置不丢），直接用
.venv/bin/python -m pip install -q ezdxf matplotlib
```

## 用法

```bash
PY=.venv/bin/python
# 3mm 板（断口 0.7mm）
$PY auto_tab.py 输入.dxf --thickness 3

# 5mm 板（断口 0.6mm）
$PY auto_tab.py 输入.dxf --thickness 5

# 非常规厚度：手动指定断口宽度
$PY auto_tab.py 输入.dxf --tab-width 0.8

# 指定输出路径 / 不输出复核图
$PY auto_tab.py 输入.dxf --thickness 3 --out 输出.dxf --no-png
```

输出：
- `输入_断口.dxf` —— 打好断口的图（原文件不动）
- `输入_断口_review.png` —— 整板复核图（橙色点=断口位置）
- `输入_断口_review_detail_N.png` —— 断口局部放大图

**交付前必做**：放大复核图，确认每个缺口实际存在。缺口看不见 = 没打。

## 脚本干了什么（按顺序）

1. **预检样条**：发现 SPLINE 直接中止（手册禁止用样条），未改动任何文件
2. **audit**：记录 audit 前后实体数，audit 偷偷删实体会告警
3. **炸开块引用**：递归炸开 INSERT（含嵌套），变换矩阵逐层累乘；炸开后颜色继承宿主设置
4. **清重复线/碎线/近重合线**：精确重复删除；<0.3mm 碎线删除；近重合/分叉线删除较短者并告警
5. **颜色校验**：白=7切透 / 红=1雕刻 / 绿=3镂空；无白线则报错退出；红绿线原样保留
6. **打断口**（只打白线直线段）：
   - 宽度：3mm→0.7mm，5mm→0.6mm（手册实测值）
   - 位置：直线段几何中点；不打圆弧/槽口/角点/端点
   - 数量：小图(<50mm)1个；中图2个（平行边错位 1/3 & 2/3）；大图(≥150mm)3个；长条形打两侧短边
7. **输出 + 自检**：新 DXF 重新打开审计（0 错误、0 残留 INSERT）+ 复核图

## 已知局限（v1.1）

- "一条线把图形切成两半要打 3~4 个"这条靠人工复核：脚本按尺寸打 2~3 个，特殊情况看复核图补
- 白线 LWPOLYLINE 会被展平为 LINE 输出（几何一致，激光软件不挑）
- 红/绿只认 ACI 1/3/7，BYLAYER 取图层色；杂色线条忽略并告警
- 圆形/圆弧零件不断口（手册要求避圆弧）

## Windows 电脑上用（3 步）

1. 装 Python：去 python.org 下载安装，**勾选 "Add python.exe to PATH"**
2. 装依赖库：命令行运行 `pip install ezdxf matplotlib`
3. 运行：`python auto_tab.py 图纸.dxf --thickness 3`

先用 `test_input.dxf` 跑一遍自测，对得上再跑真实图纸。
